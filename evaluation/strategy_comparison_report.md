## 4. Key Findings

1. **Keyword baseline is unreliable.** Title-only keyword matching misses 89-96% of relevant papers. While precision is high when it matches, the recall is too low for systematic review use.

2. **Binary LLM achieves high recall but poor precision.** Even with an ultra-conservative prompt ("exclude when uncertain, default answer is exclude"), LLMs correctly identify most relevant papers but include too many false positives. On p14, binary marked ALL 94 papers as include — offering zero screening value.

3. **5D achieves the best precision-recall balance.** Despite using only title+abstract (`nofulltext` mode) with a lightweight model (Qwen-Turbo), 5D achieves the highest F1 scores (0.25-0.64) across all projects. The dimensional scoring framework reduces screening workload by 78% while maintaining 80% recall.

4. **5D's value is not just recall — it's the dimensional evidence scoring.** Unlike binary strategies that output only include/exclude, 5D provides per-dimension scores (disease relevance, population match, location match, evidence quality, parameter relevance) with detailed justifications. This enables:
   - **Tiered confidence** (strong vs possible candidates)
   - **Downstream stratified analysis** by evidence quality
   - **Auditable decisions** with per-dimension rationale
   - **Adjustable thresholds** to balance recall vs precision

## 5. Limitations

- 5D results use Qwen-Turbo in `nofulltext` mode. The production pipeline uses DeepSeek-V4-Pro with full-text retrieval, which achieves higher recall (>95%).
- Binary LLM used the same model (Qwen-Turbo) for fair comparison. Stronger models would further increase binary recall but not precision.
- The small number of GT papers in p14 (n=9) limits statistical reliability for that project.
