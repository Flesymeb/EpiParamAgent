# Coding domain guide, version 1

Before serialization, check the source block for every in-scope estimate, including
the second value, subgroup, model, statistic and table row. Preserve those distinctions
as separate records with original quotes. A correct first estimate is not evidence
that extraction is complete. A rejected candidate needs its own scope/source reason.

Lexical source navigation and completeness diagnostics identify places to inspect;
they do not decide eligibility or fill missing numeric fields. A search miss cannot
establish that a field was not reported. Inspect original table headers and row labels
with the cell, and preserve separate exact quotes when the context is noncontiguous.

Coverage is limited to the declared supplied main/supplement sources. Missing material
must remain unknown. Never invent a record to satisfy a detected signal or a coverage
count. Only the source and the declared codebook/scope can establish an extracted field.
