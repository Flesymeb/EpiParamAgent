# Fatality and severity

- Apply the complete research question and eligibility criteria. Include severity, hospitalization, or upstream evidence only when the task allows it.
- A case fatality proportion/ratio (CFR) uses cases as its denominator; an infection fatality proportion/ratio (IFR) uses infections, including unascertained infections where estimated. Population mortality rates, survival, and severity outcomes have different meanings and denominators.
- Check the population, case definition, follow-up, deaths, and corresponding denominator. A model-adjusted estimate is not ineligible merely because it uses aggregate data.
- At title/abstract screening, missing death counts or a missing abstract are unresolved information. A plausible outcome-data path under the task can warrant full-text verification; a disease mention alone cannot.
- At full text, verify the permitted outcome and denominator in the supplied main text and supplements. Explicit zero deaths can be relevant. A case count, recovery, or silence about deaths alone does not establish zero fatality.
- When the task selects serosurveys as inputs for IFR inference, assess that evidence role rather than require a reported IFR. Computing a proportion from raw counts or using secondary studies is permitted only when the task allows that evidence form.
