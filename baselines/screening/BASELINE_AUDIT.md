## Reporting Boundary

Use the main paper table for MetaAgent, candidate general LLMs, historical
LEADS, and historical keyword-rule rows. Use
`baselines/screening/results/screening_baseline_summary.csv` as the reproducible
screening-baseline rollup because it combines that table with rerunnable
baseline-folder outputs.

Do not report AgentSLR-style ScreenPrompt Lite as a result until it has been run
without `--dry-run` and without `--limit` for a complete disease profile set.
The summary script intentionally skips dry-run, limited, and single-profile
smoke outputs because they are diagnostics, not comparable benchmark results.

## Endpoint Notes

The baseline runners read CLI arguments first, then process environment, then
project `.env.local` via `metaagent.config.load_llm_config(module_hint="screening")`.
When an endpoint serves chat completions but blocks `/models`, run:

```bash
python baselines/screening/run_all.py --run-llm --allow-missing-endpoint
```

This forwards `--no-check-server` to the underlying LLM runner.
